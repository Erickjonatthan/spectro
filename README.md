# Spectro.xum
Linguagem de programação muito dark

## Comandos

- `se`: inicia uma condição.
- `senao`: indica o caminho alternativo de uma condição.
- `ent`: palavra reservada; o lexer não define seu significado.
- `funsao`: indica uma função.
- `stopmeters`: palavra reservada; o lexer não define seu significado.
- `retorne`: retorna um valor.
- `ate`: marca o limite de uma repetição.
- `enquanto`: indica uma repetição condicionada.
- `repete`: indica repetição.
- `pare`: interrompe uma repetição.
- `ss` e `screenshot`: palavras reservadas; o lexer não define seu significado.
- `input`: indica entrada de dados.
